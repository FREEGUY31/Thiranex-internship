# Sales & Revenue Analysis Dashboard

## 📌 Project Overview
This project analyzes sales data to uncover business insights using Python.

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## 📊 Key KPIs
- Total Sales
- Total Profit
- Total Orders
- Average Sales

## 📈 Visualizations
- Sales over Time
- Sales by Category
- Top Sub-Categories
- State-wise Sales
- Payment Mode Distribution

## 🔍 Key Insights
- Highest sales observed in ___
- ___ category contributes the most revenue
- Most preferred payment mode is ___
- Sales trend indicates ___
